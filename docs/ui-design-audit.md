日期：2026-11-05。分支：`dev`。

本轮依据 `docs/ui-rules.md`、coss 实际使用方式及项目已有验收说明重新审查。源码检查覆盖共享组件、导航、Wiki 布局、成员、作品与歌曲卡片；视觉参考沿用上一轮 32 张截图，另补无 JavaScript 手机导航复核。期间未修改页面实现。工作区中的作品卡片调整属于已有改动，不归入本轮修复。

## 不再视为问题的项目

以下 Kumo UI 风格约束不适用于本项目，已从 UI 规则中撤销，不再等待用户逐个批准例外：

- 全部内容必须 14px，以及禁止 coss 在不同 size/断点使用 12px、14px 或 16px。
- 禁止任何 tracking，包括本站原本允许的 `tracking-tight`。
- 禁止 `font-bold`，或强制所有英文 UI 标题使用 sentence case。
- 禁止 hover 颜色过渡，包括 border/background 的短时过渡。
- 禁止实体 border 与轻微投影共存，或强制改为 ring。
- 禁止卡片嵌套、叠加；coss Card/CardFrame/Frame 和媒体框架继续保留。
- 仅因使用等值 padding、缺少 sticky border、没有将行内等宽字缩小到 0.9em 而判违规。

保留的通用检查包括：内容分组清晰、图片边距与圆角协调、图标文字对齐、退出动画期间排版稳定、焦点可见、响应式与减少动态效果支持。它们按实际结果检查，不固定要求某个 Kumo token、组件名、DOM 包装或挂载方式。

## 保留项与范围

共享按钮/菜单的字号差异、tracking-tight、hover 颜色过渡、Card/Menu/Dialog 的 border 配合轻微投影、独立侧栏没有 border、文本面板等值 padding 均保留。没有引入 Kumo 组件或专用 token，没有全面收窄为 14px，也没有拆除 coss 叠加结构。

工作区原有的作品卡片及数据工具调整保留。Markdown 历史资料中的作品名、引用、媒体及原文不属于本轮 UI 样式迁移；没有批量改写内容资料。主题切换按钮仍是独立功能需求，不属于本轮缺陷修复。
