# UI 规则

新写或改动的页面和组件都按这些规则做。已经采用规则的文件列在 `tests/ui-rules.test.mjs` 的 `RULED_FILES` 中，测试会检查它们；改动其他文件时，顺手把它加入这个清单。
规则后面写了测试名的，由测试检查；其余规则由人在页面上检查。

## 文字

**不用大写和宽字距。** 不用 `uppercase`，字距最多 0.02em（`tracking-tight` 和默认字距都可以，`tracking-wide` 及以上不行）。这样文字读起来平稳，和正文一致。由 `tests/ui-rules.test.mjs`（"no capitals or wide letter spacing"）检查。

**标题单独成立。** 标题下面不加更小的灰色副标题，说明写进正文。这样读者只读一个标题，不用读两个。

**每个事实只说一次。** 同一屏里，同一个事实不出现在两个地方；两个数字相等时只说一个。这样一屏能放下更多事实，两份副本也不会对不上。

**用平实的话。** 页面上不出现内部用语，例如 Song ID、slug、"关联"、"曲目记录"、数据集或字段名。我们自己写的文案里不用括号补充说明，也不用 emoji 或符号当标记；字段之间不用 "·" 一类符号分隔，需要标出字段（日期、会场等）时，在字段前放一个 lucide-react 图标。这样不了解数据结构的读者也能读懂每个字。Setlist、Live、Tour 这些站内通用的名称可以用。演出名、会场名之类的数据原文照录，不受这条限制。由 `tests/ui-rules.test.mjs`（"plain words"）检查，包括不用 "·" 分隔字段。

**关联只说数据说了的事。** 一首歌和一场公演之间，只能说"已整理的 Setlist 里有这首歌"。数据里没有记录，不能说成"没有演唱过"。这样页面说的话永远不超过数据能证明的。由 `tests/ui-rules.test.mjs`（"plain words"）检查。

**来源放在参考资料里。** 来源、链接和授权说明集中放在页面的"参考资料与官方链接"部分；正文和卡片里不夹带来源说明。这样正文保持清楚，每个来源也都有出处。

## 布局

**尺寸来自设计系统。** 间距是 4px 的倍数（Tailwind 整数档，例如 `gap-1`、`p-3`；不用 `gap-1.5`、`py-2.5` 这类半档）。字号只用 12、14、16、18、20、24、30、36px，也就是 `text-xs` 到 `text-4xl`，CSS 里写对应的 rem。控件高度用 coss 的尺寸档（`buttonVariants` 的 `size`），不另写高度。coss 组件内部的数值不算在内。这样各页面的控件、卡片和间距对得齐。由 `tests/ui-rules.test.mjs`（"sizes come from the design system"）检查。

**要紧凑就收间距，不缩尺寸。** 想让某部分更紧凑时，缩小间距、合并重复内容；字号和控件高度保持不变。这样文字始终好读，控件始终好按。粗指针设备上，控件的点击区域保持 coss 默认的 44px。

**同一组卡片高度一致。** 一组卡片使用固定结构：标题最多两行并始终预留两行，其余每个字段一行，放不下的字段截断，完整内容放在 `title` 属性里。条目多出来的部分（例如多场公演）收进 coss Menu 这类弹出层，或者链接到详情页，不让卡片变高。这样一组卡片排列整齐，扫读时视线不必跳动。

**固定控件下不压内容，窄屏不横向滚动。** 浮动目录等固定控件不能永久挡住任何名称或控件；页面在 390px 宽时没有横向滚动。这样手机上每个名称和控件都看得到。

**键盘和动效。** 键盘焦点要看得见，并且保持控件自己的形状（例如圆角控件显示圆角焦点环，不再叠一个方框）。页面遵守 `prefers-reduced-motion`，不强制平滑滚动。这样不用鼠标、关掉动效也能使用页面。

## 外观

**使用设计系统。** 颜色 token 定义在 `src/styles/global.css`，组件里只引用（例如 `var(--muted-foreground)`、`text-muted-foreground`），不写颜色字面量，也不在组件样式里重新定义 token。组件优先用 `src/components/ui/` 里的 coss 组件。这样细节（细线颜色、透明度）在各处一致。由 `tests/ui-rules.test.mjs`（"colours come from tokens"）检查。

**不加装饰效果。** 不用渐变、毛玻璃、发光、大阴影，也不用品牌色铺背景。层级靠字重、字号档和间距表达。这样信息本身最显眼。由 `tests/ui-rules.test.mjs`（"no decorative effects"）检查。

**不画标志，图标只标字段。** 站点和页面用文字命名，不自制图形标志。图标只用 lucide-react，只用来标出字段，尺寸 16px（`size-4`），颜色用 `text-muted-foreground`，并设 `aria-hidden`，含义由旁边的文字表达。不用图标做装饰。这样不会有凭空设计的图形替内容说话。

**没有图片也完整。** 很多成员、公演、作品没有海报或照片。卡片和信息框要设计成没有图片时也是完整的，不留空框。

**亮色和暗色。** 每个页面在两种主题下都可读（暗色由根元素上的 `.dark` 触发），新组件要在两种主题下都检查。站点目前还没有主题切换按钮。

**空状态要给出去处。** 列表为空时，说明现在知道什么，并给出一个能继续浏览的链接，不要停在一句"暂无"。这样读者总有下一步可走。
