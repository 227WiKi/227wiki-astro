# ナナニジライブ2023

## Live信息
<b>Live名称:</b> ナナニジライブ2023

--------

<b>举办时间:</b> 2023年1月至6月

--------

<b>会场:</b> SHIBUYA PLEASURE PLEASURE

--------

<b>出演成员:</b> 相川奈央、麻丘真央、雨夜音、清井美那、椎名桜月、四条月、月城咲舞、望月りの

## 信息

“ナナニジライブ2023”是由22/7二期成员8人出演的定期公演，共举办8场。

这是二期成员首次仅由8人进行演出的系列公演。官方会员页面会在每场公演后公开幕后Making和Live影像。
