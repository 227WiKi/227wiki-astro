# 22/7 LIVE TOUR 2022「14」

## Live信息
<b>Live名称:</b> 22/7 LIVE TOUR 2022「14」

--------

<b>举办日期:</b> 2022年3月10日 / 3月18日 / 3月19日 / 3月27日 / 4月20日

--------

<b>会场:</b> KT Zepp Yokohama / Zepp Nagoya / Zepp Namba (OSAKA) / Zepp DiverCity (TOKYO)

--------

<b>影像收录:</b> [曇り空の向こうは晴れている](/discography/releases/9th-single/) Blu-ray

## 信息

22/7 LIVE TOUR 2022「14」是22/7在二期成员加入后，以14人体制举办的首次巡演。

第9张单曲[曇り空の向こうは晴れている](/discography/releases/9th-single/)的Blu-ray中收录了2022年3月27日Zepp DiverCity (TOKYO)东京场的昼场和夜场影像。
